#### Датасет
Задача - обучение модели для поиска аномалий. Датасет представляет из себя набор изображений цельных плат и плат с проливом металла. 
Датасет разделен на три части - изображения без аномалий для обучения автоэнкодера, изображения с аномалиями для подбора трешхолда, тестовые данные с перемешанными примерами.

#### Эксперименты
В качестве первого бейслайна был обучен автоэнкодер на линейных слоях, черно-белых картинках, без аугментаций. В итоге аномальные данные оказались практически неразделимы с нормальными.

Далее был обучен сверточный автоэнкодер на RGB картинках, с добавлением аугментаций RandomHorizontalFlip(0.3), RandomVerticalFlip(0.3), RandomRotation(degrees=(-25, 25)) и нормализацией пикселей. RandomRotation оказался излишен, с ним модель обучить не получилось, значение лосс функции упиралось в большое значение (по сравнению с другими попытками обучения) и не падало, что также видно по распределению MSE:
![image](https://github.com/user-attachments/assets/5ec1d663-c439-4b92-bbab-ac7d46f525e0)

После обучения сверточного автоэнкодера была достигнута метрика f1 0.16. Чтобы её увеличить, был добавлен дополнительный слой свертки, а также увеличено их количество параметров. Добавление сверток больше трех
